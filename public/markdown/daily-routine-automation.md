# Daily Routine Test Automation

An automated testing framework designed in Java to validate web workflows, functional regression scenarios, and user routine actions with high repeatability.

## 🚀 Overview

- **Framework Architecture:** Built with Java and Apache Maven, integrating Selenium WebDriver for browser automation.
- **Test Management:** Powered by TestNG for robust test suite configuration, data-driven tests, and execution grouping.
- **Reporting & Verification:** Provides structured test logs, assertions, and execution status tracking.
- **Maintainability:** Employs modular design patterns to keep test cases clean, independent, and easily maintainable.

## 🛠️ Technology Stack

- **Language:** Java (JDK 23)
- **Testing Framework:** TestNG
- **Automation Engine:** Selenium WebDriver
- **Build & Dependency Management:** Apache Maven (`pom.xml`)
