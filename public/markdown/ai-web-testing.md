# AutoQA - AI Web Testing Platform

An intelligent, autonomous web application testing suite combining an AI agent orchestrator with modern browser automation.

## 🚀 Features

- **Automated Test Generation & Execution:** Generates and runs end-to-end browser test suites dynamically.
- **Playwright Automation Engine:** High-performance headless and headed cross-browser automation via `@autoqa/playwright-engine`.
- **Interactive QA Dashboard:** Modern React client built with Vite, TanStack React Query, and TailwindCSS for real-time test run monitoring, reports, and logs.
- **Resilient Locators & Self-Healing:** Uses smart locator strategies to reduce test flakiness and adapt to UI changes.
- **Backend API & Orchestration:** Node.js and Express backend coordinating test jobs, execution queues, and artifact retention.

## 🛠️ Technology Stack

- **Testing Engine:** Playwright, TypeScript, Node.js
- **Frontend Dashboard:** React 18, Vite, TanStack Query, React Hook Form, Lucide Icons
- **Backend Services:** Node.js, Express, REST APIs
- **Languages:** TypeScript, JavaScript
